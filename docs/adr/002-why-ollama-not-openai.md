# ADR 002: Ollama (локальный инференс), не OpenAI API

## Context

[`support-triage-llm`](https://github.com/exist-ty/support-triage-llm) классифицирует обращения клиентов (категория,
тональность, приоритет, предлагаемый ответ) через LLM поверх RAG. Нужно
было выбрать между локальным инференсом (Ollama) и облачным API (OpenAI/
аналоги).

## Decision

Ollama + `qwen2.5:3b-instruct` (генерация) + `all-minilm` (эмбеддинги),
запущенные локально на CPU этой машины.

Причины: (1) нулевая стоимость за токен на пет-проекте, который
прогоняется многократно во время разработки — счёт за API для десятков
итеративных прогонов ETL/DAG за время разработки был бы неоправдан;
(2) демонстрация конкретно локального инференса как отдельного навыка
(квантизация, ограничения CPU-инференса, отсутствие сети) — то, что
облачный API не показывает; (3) приватность — реалистичная демонстрация
паттерна для данных, которые нельзя отправлять во внешний API (реальные
обращения клиентов).

## Consequences

- **Честная цена этого решения задокументирована, а не скрыта**: ~24
  минуты на 45 сообщений на CPU-инференсе (README `support-triage-llm`,
  раздел "Честные ограничения"), деградирующая до ~51 минуты при
  совместном запуске с Airflow на этой же машине (см. ADR 001).
- **Качество ниже, чем дал бы GPT-4o-класс модели**: задокументированные
  систематические ошибки классификации (`cancel`→`return` в 6 из 6
  случаев, `off_topic`→`wholesale`) — 3B-модель без fine-tuning не
  удерживает тонкие различия интента, которые более крупная модель,
  вероятно, различила бы. Это не скрыто, а разобрано по причинам в README
  (`scripts/evaluate_llm.py`, confusion matrix).
- **Non-determinism без контроля температуры/сида** — повторные прогоны
  дают разные числа (0.69 → 0.71 → 0.73 accuracy на одном и том же
  датасете), задокументировано как честная находка, а не скрыто как шум.
- **Когда переходить на API**: как только точность/скорость важнее
  стоимости и приватность данных допускает внешний вызов — то есть в
  реальной продакшн-системе с настоящими клиентами, а не в
  демонстрационном пет-проекте. Локальный инференс здесь — осознанный
  выбор ради навыка и стоимости, не утверждение "локальное всегда лучше".

## Status

Accepted.
